# AI Itinerary Generator

A personalized travel itinerary generator project built using Python and Flask, showcasing AI concepts for travel planning.

## Features (Planned)
* Generate itineraries based on user preferences (destination, budget, travel style, interests).
* Utilize Natural Language Processing (NLP) to understand user input.
* Implement recommendation algorithms for points of interest (POIs) and activities.
* Optimize itineraries for time and location.

## Technologies Used
* Python
* Flask (Web Framework)
* Pandas (Data Manipulation)
* (More AI/ML libraries will be added here as developed: spaCy, scikit-learn, etc.)

## Setup and Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ccorreos444/kale.on.the.move.git](https://github.com/ccorreos444/kale.on.the.move.git)
    cd kale.on.the.move/ai_itinerary_generator
    ```

2.  **Create and activate a virtual environment:**
    ```bash
    python3 -m venv venv
    # On macOS/Linux:
    source venv/bin/activate
    # On Windows (Command Prompt):
    # venv\Scripts\activate.bat
    # On Windows (PowerShell):
    # venv\Scripts\Activate.ps1
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Run the application:**
    ```bash
    python app/main.py
    ```
    The application will be accessible at `http://127.0.0.1:5000/`.
